### 새로 배운 내용
#### 주제 1: 네트워크의 기본 개념과 규모
- 네트워크는 데이터와 자원을 공유하기 위해 여러 노드(기기)가 연결된 시스템으로, 실무에서는 API 통신, DB 연결 실패, 배포 문제 등을 디버깅할 때 데이터의 요청과 응답 경로를 파악하는 핵심 지식입니다.
- 네트워크 장애 발생 시 물리적 연결, 라우팅/DNS 정상 여부, 방화벽 포트 상태, 애플리케이션의 구동 상태 순서로 계층별 접근을 통해 원인을 추적해야 합니다.
- 통신 범위에 따라 개인 주변 기기를 연결하는 PAN, 사무실 등의 내부망인 LAN, 무선망인 WLAN, 논리적으로 망을 분리하는 VLAN, 대륙을 연결하는 인터넷과 같은 WAN 등으로 분류됩니다.

#### 주제 2: 주요 L1/L2 네트워크 장비 (NIC, Hub, Switch, Bridge)
- **NIC와 MAC 주소**: 네트워크 연결을 위한 하드웨어로, 각 기기는 변하지 않는 고유한 물리적 식별 번호(MAC 주소)를 갖습니다.
- **허브(Hub, L1)**: 데이터를 받으면 모든 포트로 단순 복사 전송하여 트래픽 낭비와 데이터 충돌(Collision Domain)이 발생하기 쉽습니다.
- **스위치(Switch, L2)**: MAC 주소 테이블을 기반으로 목적지 기기에만 정확하게 데이터를 전달하며, 목적지를 모를 때만 모든 포트로 플러딩(Flooding)하여 주소를 학습합니다.
- **브릿지(Bridge, L2)**: 두 개 이상의 LAN을 연결하며 트래픽을 분석해 불필요한 브로드캐스트가 넘어가지 않도록 제어합니다(현재는 스위치나 VLAN으로 주로 대체됨).

#### 주제 3: 통신 경로와 출입구 (Router, Gateway)
- **라우터(Router, L3)**: 수신한 패킷의 IP 주소와 내부 라우팅 테이블을 비교(Longest Prefix Match)하여, 데이터를 외부의 적절한 목적지로 전달하기 위한 최적의 경로를 결정합니다.
- **게이트웨이(Gateway)**: 서로 다른 프로토콜이나 망을 연결하는 네트워크의 '출입구' 역할을 수행하며, 라우터가 이 역할을 겸하거나 마이크로서비스 구조에서 API Gateway 형태로 사용되기도 합니다.
