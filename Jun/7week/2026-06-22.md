### 새로 배운 내용
#### 주제 1: AWS 네트워크 기본 (VPC, 서브넷, 보안 그룹)
- **VPC (Virtual Private Cloud)**: 공용 클라우드 내에 구축하는 독립된 가상 네트워크 환경으로, 네트워크를 분리하여 보안 위험을 최소화하고 사용자가 제어 가능한 환경을 제공합니다.
- **서브넷 구성**: 인터넷과 직접 연결되어 웹/프록시 서버를 배치하는 **퍼블릭 서브넷(Public Subnet)**과 외부 통신을 차단하여 DB 등 보안이 중요한 리소스를 보호하는 **프라이빗 서브넷(Private Subnet)**으로 나누어 구성합니다.
- **Security Group (보안 그룹)**: 인스턴스 내외부로 오가는 네트워크 트래픽을 허용하거나 차단하는 가상 방화벽 역할을 하여 보안을 강화합니다.

#### 주제 2: 클라우드 컴퓨팅과 가상화 (EC2, EBS)
- **가상화(Virtualization) 및 하이퍼바이저**: 소프트웨어(하이퍼바이저)를 통해 물리적 하드웨어를 추상화하고, 하나의 물리적 서버에서 여러 개의 가상 머신(VM)을 독립적으로 실행해 자원 효율성을 극대화하는 기술입니다.
- **EC2 (Elastic Compute Cloud)**: 클라우드 환경에서 사용자가 유연하게 생성, 구성, 관리할 수 있는 가상 서버 서비스로, 온프레미스 대비 저렴하고 확장이 용이합니다.
- **EBS (Elastic Block Store)**: EC2 인스턴스에 장착하여 데이터를 영구적으로 저장할 수 있는 클라우드 환경의 고성능 블록 스토리지입니다.

#### 주제 3: AWS 보안 및 도메인 관리 (IAM, DNS, Route53)
- **IAM (Identity and Access Management)**: AWS 리소스에 접근하는 사용자의 인증 및 인가(권한)를 관리하는 서비스입니다. 불필요한 접근을 막아 비용 누수를 방지하고 서비스 보안성을 높이는 핵심 역할을 합니다.
- **DNS 및 Route53**: 사람이 읽기 쉬운 도메인(예: naver.com)을 IP 주소로 변환하는 시스템이 **DNS**이며, AWS의 **Route53**은 이를 기반으로 빠르고 안정적인 트래픽 라우팅을 제공해 서비스 가용성을 보장합니다.
