### 새로 배운 내용
#### 주제 1: ArgoCD 개요 및 GitOps
- 쿠버네티스 클러스터의 애플리케이션 배포 및 관리를 자동화하는 GitOps 기반의 지속적 배포(CD) 도구입니다.
- Git 저장소를 '단일 진실 공급원(Single Source of Truth)'으로 삼아 클러스터의 상태를 관리합니다.
- 선언적(Declarative) 방식으로 관리되는 매니페스트 리소스를 클러스터에 실시간으로 동기화하고 상태를 일관되게 유지합니다.

#### 주제 2: ArgoCD 핵심 구성 요소 (설치된 파드)
- **argocd-server**: Web UI, API, CLI 요청을 처리하며 로그인 및 Sync 요청을 접수합니다.
- **argocd-repo-server**: Git 저장소를 읽어 Helm Chart 등의 선언적 구성 파일을 쿠버네티스 YAML 매니페스트로 렌더링합니다.
- **argocd-application-controller**: Git의 상태와 현재 클러스터 상태를 지속적으로 비교(모니터링)하고, Sync 시 리소스 배포를 실행합니다.
- **argocd-redis & applicationset-controller**: Redis는 반복 조회를 막아 속도를 높이고 부하를 줄이는 캐시 역할을 하며, ApplicationSet 컨트롤러는 dev/staging/prod 등 여러 환경의 애플리케이션을 단일 템플릿으로 자동 생성합니다.

#### 주제 3: 기타 ArgoCD 부가 구성 요소 (과제 제외 항목)
- **Dex**: SSO(Single Sign-On) 로그인 기능을 담당하며, 추후 외부 도메인 공개 및 RBAC 권한 적용 시 활성화하면 유용합니다.
- **Notifications Controller**: Sync 성공/실패 등 Application 상태 변화를 감시하여 Slack, Email, Webhook 등으로 알림을 보냅니다.
- **Commit Server**: 일반적인 배포에는 필요 없으나, Source Hydrator 기능 사용 시 렌더링된 매니페스트를 다시 Git 저장소에 푸시할 때 사용됩니다.
