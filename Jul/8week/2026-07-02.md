### 새로 배운 내용
#### 주제 1: Docker Compose의 개념과 등장 배경
- Docker Compose는 여러 컨테이너로 구성된 애플리케이션을 YAML 형식의 파일로 명확하게 정의하고, 단일 명령어로 동시에 실행 및 관리할 수 있도록 지원하는 Docker의 공식 오픈 소스 도구이다.
- 기존에는 네트워크 생성, 볼륨 설정, 데이터베이스 및 백엔드 실행 등을 위해 각각 길고 복잡한 `docker network`, `docker volume`, `docker run` 명령어를 직접 쳐야 했다.
- 서비스와 옵션이 많아질수록 위와 같은 수동 명령어 입력 방식은 실수를 유발하기 쉽고 번거롭기 때문에, 이를 해결하기 위해 도커 컴포즈가 등장하게 되었다.

#### 주제 2: YAML 문법과 docker-compose.yml의 활용
- YAML은 읽기 쉬운 텍스트 기반 데이터 표현 형식으로, 들여쓰기를 통해 계층 구조를 나타내며 `키: 값` 문법을 사용한다.
- `docker-compose.yml` 파일 내에 실행할 이미지, 빌드할 Dockerfile, 개방할 포트, 환경 변수, 네트워크, 볼륨, 서비스 의존성, 장애 시 재시작 정책 등을 한 번에 정의할 수 있다.
- Docker Compose는 컨테이너 구성, 네트워크 설정, 볼륨 관리 등의 인프라 리소스를 YAML 코드로 정의하고 관리하므로, 이는 IaC(Infrastructure as Code, 코드로서의 인프라) 도구로 볼 수 있다.
